# VNWN — Voice Notes Wolf + NLLB (Android)

Отдельное приложение на базе [Voice Notes Wolf](https://github.com/ibthe/Voice-Notes-Wolf).
Единственное отличие: перевод текста выполняет **NLLB-200 distilled 600M** (int8, ONNX Runtime)
прямо на телефоне, вместо Google ML Kit / Google Переводчика. Текст для перевода никуда не отправляется.

Приложение ставится **рядом** с оригиналом: другой `applicationId` (`app.voicenoteswolf.nllb`),
другое имя («VN Wolf NLLB»), другая иконка (оранжевый волк со значком перевода).
Данные, настройки и модели у приложений раздельные.

## Сборка
1. **Один раз** запустите GitHub → Actions → **Publish models** → Run workflow.
   Он выложит в релиз `models` модели распознавания и перевода (около 2 ГБ суммарно).
   Репозиторий должен быть публичным: приложение качает модели по обычной ссылке.
2. APK собирается при каждом push в main (Actions → **Build VNWN APK**).
   Готовый файл: **Releases → latest → VNWN-debug.apk**.
3. После установки: меню → «Модели распознавания». Для перевода нужен набор
   **«Перевод (NLLB-200, 600M)»** (около 900 МБ, скачивается один раз, докачка поддерживается).

## Как работает перевод
- `translate/NllbTokenizer.kt` — SentencePiece Unigram (Витерби) по словарю из `vocab.tsv`.
- `translate/TextTranslator.kt` — энкодер + декодер с кэшем ключей/значений, жадное декодирование.
- Языки: русский, английский, грузинский; перевод напрямую между любой парой.
- Модель грузится при первом переводе и выгружается из памяти через 90 секунд простоя.
