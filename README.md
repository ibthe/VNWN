# VNW-N — Voice Notes Wolf + NLLB (Android)

Отдельное приложение на базе [Voice Notes Wolf](https://github.com/ibthe/Voice-Notes-Wolf).
Единственное отличие: перевод текста выполняет **NLLB-200 distilled 1.3B** (int8, ONNX Runtime)
прямо на телефоне, вместо Google ML Kit / Google Переводчика. Текст для перевода никуда не отправляется.

Приложение ставится **рядом** с оригиналом: другой `applicationId` (`app.voicenoteswolf.nllb`),
другое имя («VNW-N»), другая иконка (оранжевый волк со значком перевода).
Данные, настройки и модели у приложений раздельные.

## Сборка
1. **Один раз** запустите GitHub → Actions → **Publish models** (модели распознавания, около 1,1 ГБ).
2. **Один раз** запустите Actions → **Publish NLLB 1.3B**. Готовых int8-ONNX для этой модели нет, поэтому workflow
   сам скачивает оригинал Meta, экспортирует в ONNX, квантует в int8 и проверяет пробным переводом.
   Это около часа работы. Результат попадает в отдельный релиз `nllb` (около 1,7 ГБ).
   Репозиторий должен быть публичным: приложение качает модели по обычной ссылке.
3. APK собирается при каждом push в main (Actions → **Build VNW-N APK**).
   Готовый файл: **Releases → latest → VNWN-debug.apk**.
4. После установки: меню → «Модели распознавания». Для перевода нужен набор
   **«Перевод (NLLB-200, 1.3B)»** (около 1,7 ГБ, скачивается один раз, докачка поддерживается).
   Для работы модели нужно около 3 ГБ свободной оперативной памяти.

## Как работает перевод
- `translate/NllbTokenizer.kt` — SentencePiece Unigram (Витерби) по словарю из `vocab.tsv`.
- `translate/TextPreprocessor.kt` — очистка текста перед переводом (дубли знаков, «э-э», запинки,
  сленг «щас/чё/норм», gonna/wanna) и разбиение длинных предложений (>20 слов) на фразы.
- `translate/TextTranslator.kt` — энкодер + декодер с кэшем ключей/значений, лучевой поиск (4 луча),
  штраф за повторы 1.1, запрет повторов триграмм, нормализация по длине. Параметры в `companion object`.
- Языки: русский, английский, грузинский; перевод напрямую между любой парой.
- Модель грузится при первом переводе и выгружается из памяти через 90 секунд простоя.
